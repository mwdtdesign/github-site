# 디자인·공예 실기전형 2024–2026 입시결과 (수도권·충청권)

서울·경기·충청권 대학의 디자인·공예 실기전형 입시결과와 학교별 실기·성적 반영 비율을 보여 주는 한 페이지 사이트입니다.

## 폴더 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 페이지. 열릴 때 `data/` 안의 CSV를 읽어 표·그래프·카드를 그립니다. |
| `data/history.csv` | 입시결과 (한 줄 = 한 학년도·대학·모집단위·전형의 한 가지 성적) |
| `data/methods.csv` | 전형방법 (실기 비율, 성적 비율, 성적 종류, 반영 과목, 출처) |
| `assets/` | 글꼴(Pretendard Variable)과 그래프 라이브러리(d3) |

## 데이터 고치는 법

1. `data/history.csv` 또는 `data/methods.csv`를 엑셀 등으로 고칩니다. **첫 줄(열 이름)은 바꾸지 마세요.** 저장할 때 형식은 "CSV UTF-8"로 하세요.
2. GitHub 저장소에서 `data` 폴더로 들어가 **Add file → Upload files**로 고친 파일을 같은 이름으로 올리고 **Commit changes**를 누릅니다.
3. 1~2분 뒤 사이트 주소를 새로고침하면 바뀐 값이 보입니다. `index.html`은 건드릴 필요가 없습니다.

## 출처

값은 각 대학 입학처 원문(PDF·엑셀)에서 옮겼고, 일부는 진학사 입시자료실에 게시된 대학 발표 파일에서 가져왔습니다(자료명·비고에 표시). 지원 전에는 반드시 대학 모집요강과 입학처 원문을 확인하세요.
